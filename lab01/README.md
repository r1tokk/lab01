## Опис предметної області та завдання
**Тема:** Обробка замовлень інтернет-магазину.

**Вхідні дані:** Замовлення зі списком товарів (ціна, кількість) та ознакою оплати (`paid`).
**Основне завдання:** 
- Відібрати оплачені замовлення.
- Обчислити підсумкову суму, застосувати політику знижок і податків.
- Підрахувати загальний дохід (revenue) та кількість валідних замовлень.

**Функціональні вимоги:** 
- Реалізовано "чисте ядро" (pure functions) без мутацій вхідних даних (створюються нові записи).
- Глобальний стан та I/O ізольовано від розрахункової логіки.
- Політики знижки, податку та фільтрації передаються як аргументи вищого порядку (через `typing.Callable`).

## Структура проєкту
- `core.py` — "чисте ядро" програми. Містить функції для обробки даних без побічних ефектів (`make_processor`, `order_subtotal`, `with_total`).
- `app.py` — оболонка (shell). Відповідає за побічні ефекти (I/O): створення тестових даних, ініціалізацію політик та виведення звіту (`print`).
- `tests/test_core.py` — модульні тести (`pytest`), які перевіряють референтну прозорість, відсутність мутацій та коректність роботи політик.
- `pytest.ini` — конфігурація для коректного пошуку модулів при тестуванні.
- `requirements.txt` — список залежностей проєкту.

## Інструкція із запуску

### 1. Встановлення залежностей
Переконайтеся, що ви знаходитесь у віртуальному середовищі, та встановіть необхідні бібліотеки:
```bash
pip install -r requirements.txt
```
*(Або встановіть пакети вручну: `pip install pytest mypy black ruff`)*

### 2. Запуск програми
Щоб виконати основний скрипт і побачити звіт в консолі:
```bash
python app.py
```

### 3. Тестування та перевірка коду
Запуск модульних тестів (перевірка "чистоти" функцій та логіки):
```bash
pytest
```

Перевірка статичної типізації:
```bash
mypy core.py app.py tests/
```

Форматування коду та перевірка стилю (PEP-8):
```bash
black core.py app.py tests/
ruff check core.py app.py tests/
```
